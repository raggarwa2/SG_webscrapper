## Pantip
Found it. Pantip data was gathered via two mechanisms, both in pipeline_th.py:

## 1. Live "shallow" pull — discover_pantip()

Method: requests_api (direct HTTP calls to Pantip's search endpoint, config in config_th.yaml lines 13, 143-149), no Apify actor involved.
Searches Pantip for keyword hits per tracked brand/topic.
Known cap: the search endpoint hard-limits to 10 results per keyword (confirmed via the page's own __NEXT_DATA__ always reporting last_page=true), so this only skims a shallow layer of real discourse volume.
Feeds into fact_mention.csv (Pantip channel) via entity_resolution.py → build_facts.py. Note: date_key is ~92% null for Pantip rows, so it's usable for aggregate sentiment/volume but not for time-trend analysis (flagged in rules.md 2026-08-01).
## 2. One-time bulk "deep" pull — discover_pantip_deep()

Status: one_time_run, opt-in only (--site pantip_deep).
Not a live scrape at all — it reads from a pre-existing bulk room-crawl file: pantip_room_threads v2/pantip_room_threads v2.csv.xlsx (~103,581 threads from the "โต๊ะเครื่องแป้ง" beauty room).
That file only has titles/tags, no post or comment text (comments_json is empty on every row).
Later re-mined by acne-aid-th/discovery/pantip_full_room_mine.py to search the full room dump by acne-related keywords (Thai/English) rather than just brand name, cross-referencing against 9 tracked brands and theme keywords (irritation, ingredient literacy, routine complexity, price, availability) — output in pantip_full_room_mine_by_brand.csv and pantip_full_room_mine_summary.json.
